# StudyLens

StudyLens is an intelligent, AI-powered study assistant that helps you organize your knowledge, summarize documents, and generate quizzes instantly.

## 🚀 Live Demo
**[Play with the Live App Here!](https://study-lens-fawn.vercel.app/)**

- **Frontend:** Deployed on Vercel
- **Backend:** Deployed on Render (`https://studylens-0a5j.onrender.com`)

## Features
- Upload and index PDF/PPTX lectures
- Automatic AI summaries and text extraction
- Semantic search across all your documents
- Automated quiz generation

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons, Recharts
- **Backend:** Node.js, Express, Prisma ORM, PostgreSQL (with pgvector)
- **AI Integrations:** Groq (LLM), Transformers.js (Embeddings)
